# Social media

- `posts.json`: every planned post with date, format, on-image text, caption, hashtags and alt text. The single source for the asset generator and the content calendar.
- `scenes/`: scene photos with a blank sheet that are not on the website. The website's room scenes live in `public/img/raum/`.
